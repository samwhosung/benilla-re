# ui: float constants of the static initializers

1,477 bodies of the ui files store one float computed from constants. The same few constants recur in the files that include the shared maths header: the squares of 10, 100, 5, 3, 30, 120, 20, 50, 40, 1.5 and 0.5, π doubled and its reciprocal, and the layout numbers of the products below. Each body is `fld`, one arithmetic instruction, `fstp` and `ret`; the stored float is a global of its file. The values are the results of the evaluation in table order (`ui/initthunks`), each operand read from its address as the bodies before it left it.
