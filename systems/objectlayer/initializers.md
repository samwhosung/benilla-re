# objectlayer: initializers

The static initializers of the system's object files, which the C runtime runs through its
initializer table `0x827000` before `WinMain`.

Each object file of the system has a run of initializers in the table, which opens with its +∞
(`systems/README`, Object files). An initializer is a thunk the table points at, a `jmp` or a
`call` five bytes long, and a body at the next 16-byte boundary. Most bodies store one float
computed from constants, the same 30 or so in every file that includes the shared header; the rest
store copied constants, count the files that share a start-up hook, register exit callbacks, and
build a few of the object manager's tables. Of the 984 globals the constant bodies write, 971 are
read by no other code. Every thunk the table points at is a root; the roots below are each file's
+∞ thunk.

## File names

The table gives the file of every slot: a run opens with its file's +∞ thunk and holds the file's
initializers up to the next +∞ thunk. The file's own code lies between its thunks: `0x47c480` is
the +∞ of the corpse field file, its 2π thunk is `0x47c4d0`, and the functions `0x47c4a0` and
`0x47c4b0` between them are the file's. Names are `Init<File><Kind><n>` for a body and
`Init<File><Kind><n>Thunk` for its thunk (`symbols/README`). The kinds are `Copy` for the +∞ copy,
`Double`, `Quotient`, `Square`, `Product`, `Const`, `CountUnit` and `Other`; `<n>` counts the file's
bodies of the kind in table order.
