# glue: layout

Where the system's code lies, what runs it at startup, and what nothing runs.

glue owns one run of code, from `0x46a260` to `0x475b50`: the object files of the client's
`Source\Glue` folder. In order they hold the manager and its script functions (`CGlueMgr.cpp`),
the realm list (`RealmList.cpp`), the model frame of the character screens (`CSimpleModelFFX.cpp`),
character create, character select, the survey (`SurveyDownloadGlue.cpp`), the patch
(`PatchDownloadGlue.cpp`) and the random name generator; create, select and the name generator
pass no source path. Of the 753 functions in the run, 478 are static initializers, their thunks
and their exit handlers, and one is unreached.

The system's other docs are `manager`, `flow`, `connect`, `enterworld`, `script`, `realms`, `create`,
`select`, `selectscene`, `selectghost`, `preview` and `downloads`.
