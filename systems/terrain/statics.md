# terrain: statics

The static initializers of the terrain's 30 object files: the C runtime's table of initializers
calls them once at start-up, before `main`. They hold no terrain behaviour; most store a float
constant nothing else reads.

The table runs from `0x827000`; the terrain's 945 slots lie from `0x82bb98` to `0x82ccdc`, each
object file's slots together and in the order of its code. Each file's first slot is its copy of
+∞, which is how the files are told apart (`overview`).

squares, the constant 5.0, four squares, four products, a quotient, a square and a quotient. Two
files add a counter of the files that use the network library, and the liquid file a third
quotient. The other 102 initializers build state: zeroed records and arrays, identity matrices,
empty lists, and the scene's and the map's tables. Of the 812 globals the block initializers
write, three are read by code outside the initializers.
